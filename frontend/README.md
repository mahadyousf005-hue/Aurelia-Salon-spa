# 🌸 Aurelia Salon & Spa - Frontend App

Luxury salon booking and management SPA built with React 19, TypeScript, and Tailwind CSS.

## 🚀 Quick Start

```bash
# 1. Navigate to frontend directory
cd frontend

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build for production
npm run build
```

## 📦 Deployment

You can deploy this folder directly to Vercel, Netlify, Cloudflare Pages, or Firebase Hosting:
- **Build command**: `npm run build`
- **Output directory**: `dist`
